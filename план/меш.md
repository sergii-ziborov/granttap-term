# Меш

Меш — это набор репозиториев, связанных между собой. Связь идёт не через чат, а через сами репозитории. Связи строит Weavatrix.

У каждого меша свои настройки код-хелса. Код-хелс — башни кода, как в RepoLens и в GrantTap. Файл — башня. Высота из символов и строк. Цвет — язык. Файлы стоят модулями. Внешние узлы стоят отдельно. Дороги связывают файлы и точки входа, когда они есть. В текстовом терминале эта картина строится так, как сказано в `рисунок`.

В меше сохраняются действия из чатов, у которых есть последствие для репозиториев этого меша.

В меше хранятся окружения, которые агент может взять. Там же общие навыки, в том числе навыки Claude и Codex, и агенты меша ими делятся.
