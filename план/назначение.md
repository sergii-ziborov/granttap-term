# Назначение

GrantTap Term — локальная система управления агентами. Она запускается внутри текущего терминала и не открывает своё окно. Это не сервер GrantTap и не эмулятор терминала.

Её вызывают из iTerm или из другого терминала. Графического режима у этой системы может не быть: весь интерфейс текстовый.

По SSH работают с компьютером, где система уже стоит, даже если на местной машине её нет. Местной машине не нужна установка и не нужна графика. Сессия SSH и есть терминал.

Система работает на том компьютере, где запущена. Она соединяется с Grok, Claude и Codex, которые запущены там. Внешних соединений у агентов нет.

Система написана на Rust и остаётся быстрой и маленькой. Её MCP тоже на Rust.

Внутри она использует Weavatrix как библиотеку. Агентам та же библиотека доступна как MCP и помогает в разработке. Связи между репозиториями строит Weavatrix. История и чтение Git внутри идут через Git Weavatrix. Снаружи коммиты делает обычный Git, через его командную строку.
