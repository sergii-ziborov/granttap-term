# Репозиторий и код

Виден репозиторий и меш: какие репозитории связаны. Git идёт через Weavatrix.

Код-хелс — башни кода, как в RepoLens и в GrantTap. Файл — башня. Высота из символов и строк. Цвет — язык. Файлы стоят модулями. Внешние узлы стоят отдельно. Дороги связывают файлы и точки входа, когда они есть.
