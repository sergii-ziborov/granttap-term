# Терминал

При вводе команды над строкой появляются подсказки. Строка хранит историю.

Control+V вставляет картинку в текст. Она становится меткой `[Image #N]`. Рядом видны формат, размер в точках, объём и путь. Эту картинку можно открыть и увидеть клеточным предпросмотром.

На каждую команду снизу собирается строка с её описанием. Описание открывается в сплите.
